# GreenUP：AI 時代一人公司的全自動營運系統（前端原型）

**線上展示：** 後台 https://solo.greenup.ai ｜ 銷售網頁 https://solo.greenup.ai/shop.html （所有資料皆為模擬）


> AI 時代一人公司的全自動營運系統｜綠奧智慧有限公司（GreenUP.AI）｜未來網址：solo.greenup.ai
>
> 本資料夾是**決賽展示用的前端原型**：純靜態 HTML／CSS／JS，不需要建置、不需要後端、不需要任何 API 金鑰。
> 所有客戶、訂單、金額、稅額皆為**模擬資料**（固定種子亂數產生，每次載入結果一致）。

## 如何執行

```bash
cd system
python3 -m http.server 8080
```

接著用 Chrome 或 Edge 開啟：

- 店主後台：<http://localhost:8080>（或 `index.html`）
- 客人端銷售網頁：<http://localhost:8080/shop.html>

> 必須透過 http 伺服器開啟（不能直接雙擊 `file://`），因為使用了 ES modules。
> three.js／GSAP／ECharts 已放在 `vendor/`，**現場沒有網路也能展示**。

建議兩個分頁並排：左邊 `shop.html`（客人），右邊 `index.html`（阿美）。
兩個分頁透過 `BroadcastChannel`＋`localStorage` 即時同步：客人在網頁結帳，後台立刻跳出通知，訂單、發票、分錄、庫存、KPI 同步更新。

## 功能一覽

| 區塊 | 檔案 | 說明 |
|---|---|---|
| 啟動頁 | `index.html` | 第一次開啟時顯示「客人端／店主端」入口與示範流程（按 Esc 或「進入」關閉；網址加 `?nolaunch` 可略過） |
| 總覽 | `js/views/dashboard.js` | three.js「AI 大腦」主視覺、6 張 KPI（GSAP 數字跳動）、30 天營收趨勢、通路占比、熱銷商品、下單時段熱力圖、AI 即時動態 |
| AI 聊天收單 | `js/views/chat.js` | LINE／WhatsApp／Zalo／Messenger 收件匣；日文、英文（馬來西亞）、越南文、中文客人劇本；外語訊息下方顯示中文翻譯；自動建單＋付款連結＋入帳 |
| AI 電話客服 | `js/views/phone.js` | 來電動畫、語音波形、即時逐字稿、AI 複述確認「芋泥巴斯克 2 個，寄到台中……對嗎？」、自動建單（可開啟瀏覽器語音朗讀） |
| POS 與會計 | `js/views/pos.js` | 全通路訂單＋電子發票號碼、自動會計分錄（借：銀行存款／應收帳款；貸：銷貨收入、銷項稅額 5%）、庫存與安全庫存警示、門市快速結帳 |
| 自動化報稅 | `js/views/tax.js` | 當期（雙月）營業稅試算：銷項－進項＝應納、401 申報書預覽、截止日倒數、「本人確認後送出」（模擬） |
| 用問的 | `js/ask.js`、`js/views/ask.js` | 規則式中文自然語言解析 → 文字＋ECharts 圖表＋資料來源標籤；支援語音提問（瀏覽器支援時） |
| 會議機器人 | `js/views/meeting.js` | 會議逐字稿播放 → 摘要、決議、待辦（負責人／期限）→ 一鍵轉報價單草稿 |
| 部署模式 | `js/views/deploy.js` | 雲端訂閱／企業地端／雲地混合，元件位置動畫切換 |
| 銷售網頁 | `shop.html`、`js/shop/*.js` | three.js 甜點主視覺、商品、商品詳情、購物車、結帳（模擬付款）、5 種語言切換 |
| 聊天導購機器人 | `js/shop/bot.js` | 規則式意圖比對：送禮、不要太甜、預算、運費、過敏原、保存、加入購物車、聊天內結帳；自動偵測語言並切換；麥克風語音輸入、語音朗讀回覆 |
| 多語言 | `js/i18n.js` | 繁體中文／English／日本語／Tiếng Việt／Bahasa Melayu 介面、商品名稱與說明、機器人回覆 |

左側欄下方的「重置示範資料」會清除示範中新增的訂單（兩個分頁同步清除）。

## 3 分鐘示範腳本

> 開場前：先按左下「重置示範資料」，再把 `shop.html` 與後台並排。

1. **聊天收單（約 40 秒）**
   - 後台左側點「AI 聊天收單」→ 按「模擬客人訊息」。
   - 日本客人用日文在 LINE 詢問鳳梨酥寄日本，AI 用日文回覆、每則訊息下方有中文翻譯；右側即時擷取品項／數量／寄送地，流程燈號逐一亮起。
   - 傳出付款連結 → 建立訂單＋電子發票 → 客人付款 → 右下角跳出「收款完成」。
   - （加分）切到 `shop.html`，用日文對右下角 AI 導購說「パイナップルケーキを3箱ください」，再按「お会計」→「支払いを確定」。回到後台，收件匣多一則「官網 AI 導購」對話，原文＋中文翻譯都在。
2. **電話客服（約 30 秒）**
   - 點「AI 電話客服」→「模擬來電」（可先按喇叭開啟語音）。
   - 強調 AI 會複述關鍵條件「芋泥巴斯克 2 個，寄到台中，週六前送達……對嗎？」，客人確認後自動建單，並跳出芋泥巴斯克的庫存警示。
3. **後台自動入帳（約 25 秒）**
   - 點「POS 與會計」：剛才的 LINE、電話、官網訂單都在訂單表（綠色左線代表即時訂單），已自動開電子發票。
   - 指給評審看「自動會計分錄」：借銀行存款／應收帳款，貸銷貨收入＋銷項稅額 5%；收款後自動沖銷應收帳款。
   - 在右側門市結帳點兩個商品 →「結帳並開立電子發票」，跳出電子發票證明聯。
4. **用問的（約 30 秒）**
   - 點「用問的」，依序點「上個月哪個商品賣最好？」「各通路營收比例」「毛利率」。
   - 每個答案都有逐字打出的說明、圖表，以及「資料來源：訂單資料表，期間……，查詢時間……」。
5. **報稅試算（約 25 秒）**
   - 點「自動化報稅」：銷項稅額－進項稅額＝應納稅額、401 申報書預覽、截止日倒數。
   - 強調「試算／示範」與「本人確認後送出」，按下後出現成功動畫（模擬，不會連線任何政府系統）。
6. **會議機器人（約 30 秒）**
   - 點「會議機器人」→「播放會議並產生紀錄」，逐字稿跑完後自動產生摘要、決議、待辦。
   - 按待辦旁的「轉成報價單」→ 報價單草稿自動帶入數量、單價、稅額、交期與付款條件。
7. （時間允許）**部署模式**：切換雲端訂閱／企業地端／雲地混合，頂欄的部署徽章同步變更。

## 技術說明

- 純靜態：`index.html`、`shop.html` + ES modules，`three` 透過 import map 對應到 `vendor/three.module.js`。
- 函式庫（皆已放入 `vendor/`，版本與授權見 `vendor/README.md`）：three.js 0.186（MIT）、GSAP 3.15（GreenSock Standard License，免費使用）、Apache ECharts 6.1（Apache-2.0）。
- 共用狀態：`js/state.js`（訂單、庫存、分錄、事件匯流排；`localStorage` 保存示範中新增的訂單，`BroadcastChannel` 跨分頁同步）。
- 模擬資料：`js/data.js`（約 90 天、固定種子 PRNG；商品、通路、進項憑證）。
- 效能：three.js 像素比上限 2，分頁隱藏或畫面捲出時暫停繪製。
- 語音：使用瀏覽器內建 Web Speech API（語音辨識／語音合成），不支援時會顯示提示並自動略過，不影響其他功能。

## 已知限制

- 這是展示原型：沒有真正的後端、AI 模型、金流、電子發票或報稅系統串接，所有回覆都是腳本或規則式比對。
- 「用問的」與導購機器人是規則式解析，只理解常見問法；超出範圍會回覆引導訊息。
- 語音辨識需 Chrome／Edge 且需允許麥克風；部分瀏覽器沒有越南文或馬來文語音，朗讀時會使用預設語音或略過。
- 版面以 1920×1080 與 1440×900 為主要展示尺寸，較窄的螢幕會改為單欄排列。
