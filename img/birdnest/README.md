# 嬿窩（YAN NEST）商品圖

這個資料夾的商品圖與主視覺都是 **3D 電腦渲染的示意圖，不是實際商品的照片**；瓶身、標籤、燕盞的外觀都是依品牌設定繪製的示範，網站上會註明「示意圖」。正式上架前，請換成實際商品的照片。

商品圖（`bn-*.webp`）是透明背景，柔和的接觸陰影已經烘進 alpha，放在淺色底（象牙白、白色）上效果最好；放在深色底上陰影會不明顯、玻璃瓶會偏淡。八張商品圖用同一個相機角度與燈光，排成商品格線時看起來像同一本型錄。

## 重新產生

需要 Node.js 與 Playwright（含 Chromium）。在專案根目錄執行：

```bash
node tools/render-birdnest.js            # 全部重算，輸出到 system/img/birdnest/
node tools/render-birdnest.js bn-cup     # 只算某幾張
node tools/render-birdnest.js bn-cup --preview --out /tmp/bn   # 半尺寸、少取樣的快速預覽（PNG）
node tools/render-birdnest.js hero --frames 16 --verbose         # 自訂取樣次數、顯示進度
```

- 腳本會自己開一個本機靜態伺服器，用無頭 Chromium（軟體 WebGL）開 `tools/render-birdnest.html` 逐張渲染。
- 場景、材質與構圖在 `tools/render-birdnest/`：`core.js`（累積取樣、玻璃折射、透明度與陰影合成）、`objects.js`（瓶子、標籤、燕盞、禮盒等模型）、`main.js`（每張圖的構圖與燈光）。
- 每張圖以 2 倍解析度渲染再縮小，並把幾十次微移相機與燈光位置的結果平均（反鋸齒、軟陰影、景深）。WebP／JPEG 品質會自動往下調到檔案大小上限內（商品圖 180 KB、主視覺 450 KB）。
- 軟體 WebGL 很慢，參考時間（4 核心、兩個行程同時跑）：瓶裝商品圖每張約 8–20 分鐘、`bn-cup` 約 30 分鐘、`hero` 約 1 小時、`hero-m` 約 30 分鐘、`og` 約 20 分鐘；全部依序重算約 4 小時。可以只重算改到的那幾張，或開兩個終端機分兩批同時跑。
- 有 GPU 的電腦可以加 `--gpu` 改用硬體 WebGL，會快很多（結果應大致相同，細節可能因顯示卡略有差異）。
